# Topstep Self Learning

Learn only from evidence that Glitch can identify and reproduce.

1. Current ProjectX-derived gateway state and canonical completed outcomes are facts. Hermes reviews, plans, and memory are interpretations.
2. A single outcome remains an episode or hypothesis. Promote a durable lesson only when repeated comparable outcomes support it.
3. Keep current balances, positions, buffer, payout eligibility, account phase, directives, and transient market state out of durable memory.
4. When repeated evidence supports a cognitive change, propose one compact change with target, exact instruction, evidence episode IDs, expected effect, evaluation metric, and rollback condition.
5. Automatic activation is not assumed. The deterministic worker decides whether the operator-enabled evidence threshold is satisfied.
6. When evidence contradicts a lesson, append the contradiction and reduce, revise, or retire confidence. Never erase the original record.
7. Never alter gateway policy, credentials, risk limits, account scope, provider orders, code, or human controls.
